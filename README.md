# 🐶 Flappy Doggy

A one-tap arcade flyer where a very determined dog just wants to get through a house full of vacuum cleaners.

## 🎮 Play Now
👉 [Play the game here]( )

## Features
- 🐶 Simple one-tap flap controls
- 🌀 Vacuum-pipe obstacles that get tighter as your score climbs
- 🪙 Collectible coins to earn as you fly
- 🛡️ Unlockable shields that give you an extra life on a crash
- 🎨 Unlockable dog skins
- 🏆 Best score saved automatically
- 📱 Works on both desktop and mobile — no install needed

## Built With
- HTML, CSS, and vanilla JavaScript
- No frameworks, no build steps — just one self-contained file

## How to Play
Tap or click to flap and keep your dog in the air. Fly
